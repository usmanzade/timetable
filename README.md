# 📅 Расписание СПбГУ

**Быстрое, плавное и красивое приложение расписания для студентов СПбГУ на Android**

Выберите свою группу один раз — и каждый раз видите актуальное расписание: календарь, занятия дня, уведомления о переносах и отменах, виджет на рабочем столе.

## 📲 Установка

1. Скачайте APK из [последнего релиза](https://github.com/usmanzade/timetable/releases).
2. Разрешите установку из неизвестных источников и откройте файл.
3. Запустите приложение, нажмите «Выбрать» и найдите свою группу.

Требуется Android 8.0 и новее. Приложению нужны только доступ в интернет и, для уведомлений об изменениях, разрешение на уведомления (Android 13+).

## ✨ Возможности

### 📆 Расписание
- Расписание **группы** или **преподавателя** с `timetable.spbu.ru`
- Календарь сверху, занятия выбранного дня снизу; при запуске выбран сегодняшний день
- Три режима календаря: **день / неделя / месяц**
- Дни с занятиями отмечены цветом числа; у выбранного дня цвета инвертируются
- Свайп вверх по занятиям плавно сворачивает месяц до недели, свайп вниз разворачивает обратно
- Свайп по списку листает дни, свайп по календарю листает месяцы и недели
- Кнопка **«Сегодня»** появляется слева в верхней панели, когда выбран другой день
- Плавное появление списка занятий: снизу вверх при выборе более позднего дня, сверху вниз от календаря при более раннем
- Офлайн-режим: загруженные недели хранятся на устройстве, при потере связи показывается сохранённое расписание

### 🧾 Занятия
- Компактная карточка: время начала и конца, название, вид занятия, статусы
- Статусы: идёт сейчас, отменено, есть изменения (перенос, другая аудитория, замена преподавателя)
- Нажатие на занятие открывает окно с полной информацией: дата, время, место и формат, преподаватели, группы
- **Адрес — ссылка на приложение карт** (для дистанционных и онлайн-занятий ссылки нет)
- **ФИО преподавателя — ссылка на его расписание**: смотреть можно, не добавляя в избранное, а из просмотра преподавателя можно добавить его в избранное
- **Умный поиск преподавателя** — клик по ФИО с первого раза открывает именно нужного человека, даже если в университете есть однофамильцы

### ⭐ Избранное
- Несколько групп и преподавателей, быстрое переключение чипами над календарём
- Свои названия для групп и преподавателей: переименование и сброс к исходному
- Одинаковые по размеру карточки, на планшетах сетка из нескольких столбцов
- Поиск преподавателя по фамилии

### 🔔 Уведомления об изменениях
- Фоновая проверка расписания избранного через WorkManager с периодом от 15 минут до 6 часов
- Шесть типов изменений, каждый включается отдельно: новое занятие, удалено, отменено, перенос времени, другая аудитория, замена преподавателя
- Журнал изменений с отметкой непрочитанных и индикатором на иконке навигации
- Кнопка «Проверить сейчас»
- Настройки уведомлений скрываются, когда проверка выключена

### 🧩 Виджет
- Выбор группы или преподавателя и режима (день / неделя) при добавлении, перенастройка в любой момент
- Стрелки для листания дней и недель, переключение «День / Неделя», возврат к сегодняшнему дню
- Переключение между избранными прямо с виджета
- Прокручиваемый список занятий, в недельном режиме с заголовками дней
- Время занятий окрашено в цвета видов занятий

### 🎨 Персонализация
- Темы: системная, светлая, тёмная; динамические цвета системы (Android 12+)
- Русский и английский язык с мгновенным переключением, название приложения меняется вместе с языком
- Свои цвета для каждого вида занятий: лекция, семинар, практика, лабораторная, экзамен, зачёт, консультация, другое. Функция включается отдельно
- Выбор цвета: готовые цвета, палитра, HSV-спектр, RGB-ползунки и HEX

### 📱 Планшеты
Интерфейс адаптирован под планшеты и большие экраны.

## 🖌️ Дизайн

- Интерфейс построен на [**MIUIX**](https://github.com/compose-miuix-ui/miuix): карточки, настройки, диалоги и цвета в стиле HyperOS
- **Liquid glass** на Android 13+: плавающая капсула навигации с размытием фона, бликом по краю и пружинящим индикатором выбранного пункта
- На более старых версиях Android обычная панель навигации MIUIX
- Анимации везде: переходы между вкладками, смена месяцев и недель, пружинящее выделение дня, каскадное появление карточек, всплывающая кнопка «Сегодня», сворачивание календаря вслед за пальцем
- Адаптивная иконка приложения с поддержкой тематических иконок
- Edge-to-edge интерфейс

## ⚙️ Особенности реализации

- **Лёгкость.** Нет DI-фреймворков, баз данных и сетевых библиотек: сеть на `HttpURLConnection`, кэш в JSON-файлах, настройки в SharedPreferences
- **Скорость.** Расписание из кэша показывается мгновенно, свежие данные подгружаются в фоне и только для устаревших недель
- **Сравнение расписаний.** Фоновая проверка сверяет новую версию с отдельным снимком, поэтому изменения не «съедаются» открытием приложения
- **Устойчивый разбор данных.** Неизвестные поля ответа сайта игнорируются, формат расписания не ломает приложение
- **Без слежки.** Нет аналитики, рекламы и сторонних сервисов: все данные хранятся только на устройстве

## 🚀 Сборка

### Локально
```bash
./gradlew assembleRelease
```
Нужен JDK 27. APK появится в `app/build/outputs/apk/release/`.

### GitHub Actions
Workflow `Build` собирает приложение при каждом push, pull request и раз в неделю.

Для подписи release-сборки добавьте секреты репозитория:

| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64: `base64 -w0 release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Без секретов release подписывается debug-ключом.

### Публикация релиза
Каждый push в `main` (и любой тег `v*`) при наличии секретов подписи собирает подписанный APK и публикует его в [Releases](https://github.com/usmanzade/timetable/releases):
- тег и название берутся из `versionName` в `app/build.gradle.kts`
- если релиз с таким тегом уже есть, APK в нём обновляется, иначе создаётся новый
- чтобы выпустить новую версию, увеличьте `versionName` и `versionCode` и сделайте push

Pull request'ы и еженедельная проверка релиз не публикуют. Без секретов подписи сборка проходит, но релиз не создаётся.

## 🔄 Автообновление зависимостей

- **Dependabot** ежедневно проверяет версии из `gradle/libs.versions.toml`, GitHub Actions и JDK; связанные пакеты (Kotlin, Compose, MIUIX, AndroidX) обновляются одним pull request
- **JDK**: актуальная версия хранится в `.github/jdk/Dockerfile` (образ Temurin), Dependabot открывает pull request при выходе новой, а `build.yml` берёт версию оттуда
- **Update Gradle Wrapper** ежедневно обновляет Gradle Wrapper
- **Dependabot auto-merge** автоматически вливает минорные и патч-обновления после успешной сборки, мажорные ждут проверки

Один раз в настройках репозитория включите: Actions → «Allow GitHub Actions to create and approve pull requests», General → «Allow auto-merge», а для ветки `main` сделайте обязательной проверку `build`.
